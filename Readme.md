# 🤖 ChetanAI – AI Study Buddy (Rule-Based Chat Assistant in Python)

ChetanAI is a simple rule-based chatbot developed using Python. It allows users to interact with a chatbot through text-based conversations and receive predefined responses to common questions.

This project is created to understand the fundamentals of Python programming, including dictionaries, functions, loops, conditional statements, and string manipulation.

## 🚀 Features

- 💬 Interactive text-based conversation
- 🧠 Dictionary-based chatbot memory
- 😊 Responds to greetings and common questions
- 💡 Provides motivational messages
- 🔄 Continuous conversation using a while loop
- 👋 Exit functionality using the `bye` command
- 🐍 Built entirely with Python

## 🛠️ Technologies Used

- Python 3
- VS Code (Development Environment)

**Step 2:** Open the project folder.

